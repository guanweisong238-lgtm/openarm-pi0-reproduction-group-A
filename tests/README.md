
# Tests

本目录用于存放 OpenArm + MuJoCo + π0 / OpenPI 项目的测试代码。

## 1. 测试分类

### 仿真接口测试

由 A1 主要负责：

- 验证仿真环境能够正常启动。
- 验证关节控制接口。
- 验证相机图像、关节状态和夹爪状态的读取。
- 检查动作输入是否合法。

### 模型接口测试

由 A2 主要负责，A3 配合：

- 验证模型能够正常加载。
- 验证模型输入格式。
- 检查模型输出的动作维度和数值范围。
- 验证模型输出与实际数据定义的一致性。

### 闭环执行测试

由 A3 主要负责：

- 验证动作可以发送到仿真环境。
- 验证执行动作后能够获取新的观测。
- 验证模型预测、动作执行和观测更新的循环。
- 记录执行异常和失败案例。

## 2. 测试规范

1. 每项测试应明确测试目的和预期结果。
2. 测试失败时记录错误信息和复现步骤。
3. 涉及随机初始状态的测试应尽可能记录随机种子。
4. 测试结果应与代码版本和相关配置对应。
5. 不得仅凭程序没有报错就认定测试通过。

## 3. 当前状态

目前为测试规范阶段。

待实际接口确定后，再逐步编写和运行测试脚本。
