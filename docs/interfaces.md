# 项目接口规范

2026-10-23冻结本轮CELL联调接口。A1代码在同级工作树 `openarm-a1/`，A2代码在本项目；两者保持独立虚拟环境，通过无pickle的NPZ交换观测，不依赖同级 `openpi/` 源码目录。

## 1. 场景与初始化

场景为A1的 `openarm_mujoco/v2/cell/demo.xml`，子模块版本 `a3c8a57ec15d385e3c1dbd3fd090ee486b7f258c`。使用 `simulation.policy_env.OpenArmPolicyEnv` 时必须显式传入CELL的scene_path，包装器默认场景仍为pedestal。

CELL有17个执行器；模型只控制双臂16维，额外升降轴保持home控制目标0，并非机械锁定。reset恢复场景home；当前联调额外用2秒平滑移动、5秒保持定位episode 0首帧，此初始化不等于全部任务条件已对齐。

## 2. 观测及模型输出

| 字段 | 约定 |
| --- | --- |
| observation.state | (16,) float32实际位置；右臂七关节、右夹爪、左臂七关节、左夹爪 |
| observation.images.ceiling | (600,960,3) RGB uint8，camera_ceiling |
| observation.images.wrist_left | 同上，camera_wrist_left |
| observation.images.wrist_right | 同上，camera_wrist_right |
| prompt | Pick up the cube. |
| timestamp | 实际仿真物理时间，秒 |
| 模型输出actions | 已反归一化的(16,16)绝对位置目标，第一轴为未来16步 |

三路图像来自同一物理时刻，保留CELL原有相机。A2负责RGB适配、224×224缩放、分词、训练集统计归一化、内部32维补齐和输出反归一化，调用方不重复处理。数值按仿真弧度解释，采集版本及完整标定仍待核实。

## 3. 执行及反馈

- step(action)只接受单步(16,)有限位置目标。
- 包装器已按执行器名称完成双向重排，A3不得再次交换左右臂。
- 名义30Hz，物理步长1ms，以33/34子步调度，时间误差不累计。
- 限幅取执行器控制范围与关节几何范围的交集；返回control.requested、control.applied、control.clipped_mask。
- control.applied是目标，不能代替实际状态。推理期间仿真是否暂停、动作块执行长度和墙钟调度由A3实现并记录。

## 4. 验收证据及待完成项

CELL的episode 0示教263帧全部执行，用户目视确认成功抓取并放入托盘。平均绝对状态误差0.004115203 rad，最大0.066250473 rad，右夹爪64帧目标被限幅。首帧最大误差0.020106554 rad，严格0.02 rad检查未通过。任务成功证据为人工观察，标定仍未验收。

此结果属于示教动作回放。当前LoRA仅完成10步试训练；先验证仿真快照推理，再推进短动作执行和循环重观测。模型自主抓取、更多轨迹、自动成功判定、正式训练及批量闭环评估待完成。

## 5. 本次模型链路实测

仿真首帧快照进入A2的10步LoRA检查点，输出(16,16)，有限值及固定噪声重复性通过。首次推理约2.884秒，第二次约0.185秒；全部预测目标位于位置限位内，首步目标相对当前状态最大差值0.586064 rad。

随后在无窗口CELL中重建相同初始状态，执行预测前4步，物理时间推进0.133秒，状态均有限、无目标限幅、升降轴目标保持0；实际状态相对初始最大变化0.646591 rad。此处没有速率约束或循环重推理，不作为平滑性或任务成功的证据。下一阶段为可视化短动作及循环重观测推理，不能将当前结果写成闭环任务成功。
