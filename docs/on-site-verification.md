## 第 1 项 PCAN 端口与左右臂

**已确认。** 三方证据一致：

1. 用户现场沿线目视：黑盒丝印 CAN1 的口接右臂，CAN2 接左臂；黑盒经 USB 扩展坞直连电脑，即 PEAK 适配器本体，中间无转接盒。
2. 本机内核记录（用户执行 `sudo dmesg | grep peak_usb`）：`can0: attached to PCAN-USB Pro FD channel 0`、`can1: ... channel 1`。
3. **旧遥操作手册明文接线记录**：`vr_teleoperation/docs/实机_WebXR_操作手册.md` 第 31–36 行：

   ```
   CAN 盒：
   物理 CAN1 -> Linux can0 -> 右臂
   物理 CAN2 -> Linux can1 -> 左臂
   ```

4. 官方驱动配置 `openarm_driver/configs/openarm_pedestal.yaml`：`can_interface: right_arm: can0 / left_arm: can1`。

结论：**can0 = 右臂 R，can1 = 左臂 L**。左/右的观察方向仍按"以工作台为前、观察者站机器人背后同向看"。
