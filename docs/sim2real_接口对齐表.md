## 4. 第一批应索取的样本

- 一份原始真机观测：各路RGB、实际状态、任务指令及时间信息；若尚无样本，先给字段说明。
- 一份模型能够接收的输入，以及对应输出样例，写明原始网络输出还是已转换控制目标。
- 一个只读状态的控制示例，以及已被现场验证的动作命令示例和停止说明。
- 一份冻结的检查点与预处理/后处理说明，或可访问的推理接口说明。

样本应尽量含形状、dtype、单位、关节名和版本；仅有向量数字不够确定真实语义。
