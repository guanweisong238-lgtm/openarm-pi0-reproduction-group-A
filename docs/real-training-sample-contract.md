# 真机探索性训练样本协议（草案）

日期：2026-11-21。本文固定首轮探索性训练的数据语义；转换器、探索性数据集和 1,000 步离线训练已完成；真机闭环尚未验收。四路相机全部用于训练；已采用 30 Hz 因果对齐、224×224 等比例缩放填充，动作窗口为 50 个时间步。

## 任务

任务文本应覆盖完整目标：左臂拉开抽屉，右臂抓取方块并放入抽屉、释放，左臂推合抽屉。候选文本：

> 用左手拉开抽屉，右手抓起方块并放入抽屉、释放，然后用左手推合抽屉。

原始 `metadata.yaml` 中的任务文本不包含推合抽屉。候选文本是处理后训练样本的协议草案，不修改原始元数据；具体措辞在构建数据集前冻结。

## 单个样本

| 字段 | 形状 / 类型 | 含义与来源 |
| --- | --- | --- |
| `episode_id` | 字符串 | 原始轨迹编号，用于追溯和按轨迹划分。 |
| `timestamp_ns` | 整数 | 训练样本参考时间戳，单位纳秒；参考相机及边界规则待确定。 |
| `prompt` | 字符串 | 上述完整任务指令。 |
| `images` | 相机名到 RGB 图像的映射 | 从 JPEG 解码，必须包含 `global`、`chest`、`wrist_left`、`wrist_right`；图像尺寸、裁剪及模型映射待确定。 |
| `state` | `(16,)`，float32 | 当前双臂观测 `qpos`，右臂 8 维在前、左臂 8 维在后，单位 rad。 |
| `actions` | `(H, 16)`，float32 | 当前及未来时间步的双臂 IK 绝对角目标；每步顺序和单位与 `state` 相同。`H = 50`。 |
| `action_valid` | `(50,)`，bool | 动作窗口中真实有效的时间步；尾部填充如何参与损失须由训练适配器明确实现。 |
| `provenance` | 结构化信息 | 保留所用原始文件和时间戳、匹配偏差及转换配置版本；具体序列化格式待确定。 |

每臂 8 维依次为 `J1, J2, J3, J4, J5, J6, J7, 夹爪电机角度`，因此完整向量为 `[右 J1…J7, 右夹爪, 左 J1…J7, 左夹爪]`。夹爪值是电机角度，不是开口宽度。单位、顺序和驱动语义由采集侧提供，原始外部源码尚未在当前工作区独立复核，详见[动作语义核验](../data/real_data_20261121_193807_动作语义核验.md)。

这是一份**语义协议**，字段名和组织形式不是现有训练加载器已支持的格式；后续适配层应明确映射到模型实际输入。

## 时间和动作语义

- 离线训练样本频率为 30 Hz，约 33.33 ms 一步；50 步对应约 1.67 秒的控制时域，若从当前时刻起按 30 Hz 取 50 个时间点，首末时间戳间隔约 1.63 秒；图像约 30 fps，状态和 IK 目标原始记录约 250 Hz，必须使用时间戳而非行号对齐。
- `actions` 是记录的 IK 绝对角度目标，处于驱动限位、限速及安全检查之前，不代表最终 CAN 指令或实际位置。
- 原始相机时间是主机接收时刻，不代表曝光同步。匹配方式、偏差门限和各路时钟一致性尚未验收，需在转换器中显式记录并检查。
- 不跨 episode 生成动作窗口。边界处的填充值和有效掩码须一起保存；具体填充策略待训练适配器确定。
- 30 Hz 是离线采样协议，不决定未来真机动作发送频率。
