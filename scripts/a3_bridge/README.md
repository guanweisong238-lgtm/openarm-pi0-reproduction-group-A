
# A3：闭环执行与评估

## 1. 任务目标

连接 π0 / OpenPI 模型与 OpenArm + MuJoCo 仿真环境，将模型预测的动作转换为仿真环境可执行的控制指令，实现自主执行与闭环测试。

## 2. 主要任务

### 阶段一：基础控制

- [ ] 了解 A1 提供的仿真控制接口
- [ ] 编写独立的动作执行测试脚本
- [ ] 验证执行动作后能够获取新的观测
- [ ] 检查动作范围和控制频率

### 阶段二：模型接口

- [ ] 与 A2 确认模型输入和输出格式
- [ ] 确认模型输出动作的维度、单位和归一化方式
- [ ] 编写模型输出到仿真控制指令的转换接口
- [ ] 处理动作限幅和异常输出
- [ ] 实现模型预测、动作执行、获取新观测的循环

### 阶段三：测试与评估

- [ ] 验证模型能够重新加载并自主执行
- [ ] 实现批量仿真测试
- [ ] 记录任务成功率
- [ ] 记录任务完成时间
- [ ] 记录推理延迟
- [ ] 整理失败案例及原因
- [ ] 录制演示视频

## 3. 交付物

- 仿真动作执行测试脚本
- 模型与仿真环境的连接代码
- 闭环推理代码
- 批量评估脚本
- 测试结果表
- 失败案例记录
- 演示视频

## 4. 注意事项

1. 在模型接口尚未准备好时，可以使用固定测试动作验证控制流程。
2. 不要直接假设模型输出可以作为机械臂控制指令，必须验证动作定义、维度、单位及归一化方式。
3. 模型输出应经过必要的合法性检查和动作限幅。
4. 测试时记录代码版本、模型版本、初始状态和随机种子。
5. 不将大型视频、模型权重或完整数据集直接提交到 GitHub。
