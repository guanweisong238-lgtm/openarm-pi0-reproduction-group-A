
# A2：π0 模型与训练

## 1. 任务目标

基于 OpenPI 官方开源代码和预训练模型，验证模型推理流程，选择并适配公开数据集，完成至少一次 π0 LoRA 微调。

## 2. 主要任务

### 阶段一：环境与模型

- [ ] 检查 OpenPI 官方仓库及运行要求
- [ ] 确认可用 GPU 型号与显存
- [ ] 配置模型运行环境
- [ ] 下载或获取预训练模型权重
- [ ] 运行官方推理示例并记录结果

### 阶段二：公开数据集

- [ ] 确认选用的数据集名称和来源
- [ ] 记录数据集版本及使用许可
- [ ] 检查机器人类型、任务内容、观测和动作定义
- [ ] 验证数据能否被 OpenPI 读取
- [ ] 配合 A1 确认数据与 OpenArm 的兼容性

### 阶段三：模型微调

- [ ] 确认训练配置及数据处理方式
- [ ] 完成至少一次 LoRA 微调
- [ ] 保存训练日志和损失曲线
- [ ] 保存模型权重及对应配置
- [ ] 验证训练后的模型可以重新加载

## 3. 交付物

- 环境配置和运行说明
- 模型来源与版本记录
- 数据集来源及适配说明
- 训练配置
- 模型权重获取方式
- 训练日志与损失曲线
- 模型推理测试记录

## 4. 注意事项

1. 优先使用 OpenPI 官方代码和预训练模型。
2. 不直接假定公开数据集能够控制 OpenArm，需要先检查观测格式、动作空间和任务是否匹配。
3. 不将大型模型权重或完整数据集直接提交到 GitHub。
4. 记录实际使用的代码版本、数据版本和训练参数。
5. 如果遇到显存不足、依赖冲突或动作维度不匹配，应记录错误信息和处理过程。
