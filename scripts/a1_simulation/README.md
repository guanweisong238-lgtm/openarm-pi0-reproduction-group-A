# A1：仿真环境与数据适配

## 1. 任务目标

搭建 OpenArm + MuJoCo 仿真环境，为 π0 / OpenPI
提供机器人观测和动作控制接口。

## 2. 主要任务

- [ ] 验证 OpenArm 模型能否正常加载
- [ ] 验证机械臂关节控制接口
- [ ] 获取相机图像、关节状态和夹爪状态
- [ ] 整理环境启动与重置方法
- [ ] 配合 A2 确认模型所需的观测格式
- [ ] 检查公开数据集与仿真接口的兼容性
- [ ] 编写数据转换与校验工具

## 3. 交付物

- 仿真环境启动说明
- 可运行的仿真脚本
- 观测与动作接口说明
- 数据转换及校验工具
- 仿真运行截图或录像

## 4. 注意事项

关节数量、动作维度和控制频率等参数，
以实际使用的机器人模型、仿真接口和数据集定义为准。
