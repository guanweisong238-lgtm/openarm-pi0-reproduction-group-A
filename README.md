# OpenArm + MuJoCo + π0 / OpenPI 复现项目（A组）

## 1. 项目简介

本项目用于复现基于 π0 / OpenPI 的机器人视觉—动作策略，并在 OpenArm + MuJoCo 仿真环境中验证模型的动作执行能力。

**阶段目标：** 完成公开数据准备与适配、预训练模型推理、LoRA 微调、仿真闭环执行和定量评估。

**执行周期：** 2026-10-20 至 2026-11-19

**当前阶段：** 阶段 I：仿真复现

**本阶段不要求：** 提出新算法、完成论文发表或部署真实机械臂。

## 2. 技术路线

1. 搭建 OpenArm + MuJoCo 仿真环境。
2. 选择并验证 π0 相关公开数据集，记录数据来源、版本及许可。
3. 运行 OpenPI 官方预训练模型推理示例。
4. 检查数据格式、机器人状态与动作定义之间的兼容性。
5. 完成数据适配和至少一次 π0 LoRA 微调。
6. 将模型预测的动作接入 MuJoCo，实现闭环执行。
7. 开展批量仿真测试，统计成功率、任务完成时间和推理延迟。
8. 整理实验结果、失败案例和复现报告。

注意：公开数据集不一定与 OpenArm 的双臂任务直接兼容，需要先验证机器人类型、观测格式、动作空间及任务内容。

## 3. 成员分工

### A1：仿真环境与数据适配

- 搭建 OpenArm + MuJoCo 环境。
- 验证关节控制、相机图像、机器人状态和夹爪接口。
- 建立环境启动与重置脚本。
- 负责公开数据的格式转换、时间同步和数据校验。

### A2：π0 模型与训练

- 配置 OpenPI 环境并运行官方推理示例。
- 下载和管理预训练模型。
- 选择、下载并验证公开数据集。
- 完成数据读取配置和至少一次 LoRA 微调。
- 保存训练配置、权重及训练日志。

### A3：闭环执行与评估

- 建立模型与仿真环境之间的动作接口。
- 将模型预测转换为仿真环境可执行的动作。
- 实现动作限幅、控制频率管理和闭环推理。
- 完成批量测试、失败记录、指标统计及演示视频。

### 组长职责

- 协调三个模块的接口与依赖。
- 跟踪每周任务和验收情况。
- 维护项目文档、实验记录和代码版本。
- 组织集成测试并整理阶段性报告。

## 6. 数据与模型管理规范

- 使用经过确认的公开数据集，不默认重新采集示教数据。
- 记录数据集名称、来源链接、版本、许可和预处理方法。
- 记录模型来源、权重版本、训练配置及实验编号。
- 不直接向 Git 提交大型数据集、模型权重、缓存或虚拟环境。
- 数据集与模型权重通过适当的独立存储方式管理，并在文档中说明获取方法。
- 不将密码、访问令牌、私钥或其他敏感凭据提交到仓库。

## 7. 实验与评估

- 实验编号与日期
- 代码版本与配置

- 模型权重与训练参数
- 测试初始状态和随机种子
- 任务成功率
- 任务完成时间

- `main` 分支用于保存经过验证的项目版本。

- 合并代码前检查运行结果、依赖变化和文档更新。
- 环境、数据格式或动作接口发生变化时，及时更新相关文档。
