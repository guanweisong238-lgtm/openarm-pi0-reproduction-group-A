- 原始文件保持只读。派生目录为 `processed/real_20261128_202032_alignment_v001/` 和 `processed/real_20261128_202032_candidate_v001/`。训练运行保存了候选清单、归一化统计和筛选依据。 [本轮训练配置](../results/real_20261128_202032_pi0_lora_1000_v001/config.json)
