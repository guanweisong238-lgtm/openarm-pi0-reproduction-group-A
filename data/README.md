- [ ] 数据集能够正常下载或访问

- [ ] 已确认动作表示方式和动作维度

## 3. 数据版本与处理记录

每次处理数据时，应记录：

- 原始数据集名称与版本

- 归一化与转换方法
- 处理后的数据规模
- 数据校验结果

## 4. 数据存储规范

1. 不直接提交完整数据集或大型数据文件。
2. 在本文件中记录数据来源、版本和获取方法。
3. 不将未经验证的数据标记为可用于训练。
4. 如果修改数据处理流程，应保留相应记录。
5. 遵守原始数据集的使用许可。
