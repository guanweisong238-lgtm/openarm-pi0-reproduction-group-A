# 轨迹 17 动作突变诊断

## 范围

检查的是完整轨迹离线展示中的 590 帧；模型每 15 帧读取真实记录的观测重预测一次，取新动作窗口的前 15 帧，最后一段覆盖结尾。MuJoCo 展示脚本直接把预测 IK 目标写到仿真关节并执行正运动学，不进行物理步进、驱动限速或平滑。它不是闭环控制实验。

以每对相邻 30 Hz 帧中 14 个手臂关节的最大角度变化作为指标：重预测边界共 36 个，非边界 553 个。0.1 rad 只是对比统计阈值，不是安全限位。

| 数据／设置 | 边界变化中位数 | 边界最大值 | 边界超过 0.1 rad | 非边界变化中位数 |
| --- | ---: | ---: | ---: | ---: |
| 每次重预测使用不同噪声种子 | 0.264 rad | 0.867 rad | 35/36 | 0.0093 rad |
| 每次重预测使用固定噪声种子 | 0.172 rad | 0.764 rad | 29/36 | 0.0058 rad |
| 记录的真实手臂观测 | 0.014 rad | 0.077 rad | 0/36 | 0.0142 rad |

原始展示中最大的手臂突变位于约 8.5 秒、左 J5；在相邻帧对应的两个不同预测窗口之间约 0.867 rad。两条相邻预测窗口对同一未来时刻的目标不一致，而不是单纯在一个预测窗口内部大幅变化。真机观测在这些重预测边界没有相同数量和幅度的跳变。

## 噪声对照

重新对同一条轨迹和同一套重预测时刻推理，仅将每次预测的种子由 `70000 + 起点帧` 改为始终 `70000`；模型权重、真实输入和时序相同。固定种子降低了边界变化中位数，但 29/36 个边界仍超过 0.1 rad。对同一时刻的真实观测，两种种子方案产生的第一个目标在 36 个不同种子窗口上的最大关节差中位数约 0.144 rad；首个两次使用相同种子的窗口差为 0。数据支持“采样噪声是一个影响因素”，但不能证明它是唯一原因；该对照只有一条轨迹和一个固定种子。

## 限制

记录的 IK 目标本身也包含一些夹爪命令突变（全轨迹最大约 0.786 rad），不能把所有差异归咎于模型；它与真实测量关节角不是相同信号。显示时夹爪目标被截到旧 MuJoCo 模型范围，但手臂关节不经平滑直接赋值，因此不代表真机运动、驱动限速效果或模型自主闭环稳定性。也不能仅凭此结果认定训练轮次或相机偏差是具体原因。

`joint_jumps.png` 展示了两种噪声方案的手臂预测目标与实测手臂观测的相邻帧变化；`diagnosis.json` 保存完整统计、极值位置及输入哈希。重现：先按 `eval_real_episode_replan.py --noise-mode fixed` 生成独立固定噪声结果，再用 `/usr/bin/python3 scripts/a2_pi0/analyze_real_episode_jumps.py`。没有向真机发送动作。
