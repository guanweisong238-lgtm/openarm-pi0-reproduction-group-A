## 两项实现修复

训练的一步端点预测改为与部署相同的KV-cache路径，探针预测差为0。并发现上游策略加载器会把50,087,968个训练时float32可训练参数全部舍入为bfloat16；已新增保留检查点精度的加载器。019初态成对审计的首个目标点差约0.14–0.27mm，见 [精度审计](precision_audit_019/report.json)，这只是数值证据，不证明任务失败由它单独造成。

旧模型没有推荐精度字段时默认保持历史bfloat16。新检查点明确推荐 `checkpoint`，运行时记录实际精度。模型评估不修改历史训练协议快照。
