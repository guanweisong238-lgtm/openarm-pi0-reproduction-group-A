# MuJoCo 固定恢复器最小试验

本实验针对 episode 0 第 0 帧的训练集观测，固定选取该帧为参考；对双臂添加最多 ±0.06 rad 的人工扰动，通过 MuJoCo 执行器和 `mj_step` 运行，恢复器基于实际仿真关节反馈给出速度、加速度受限的位置命令。30 Hz 记录关节观测、绝对目标、速度和四张 MuJoCo 合成图，见 `trajectory.npz` 和 `images/`；`recovery.mp4` 是对应四视角的录像。夹爪目标固定。桌面与抽屉参与碰撞检查，场景中无关的门、阀被禁用。启动前检查起点和线性参考路径的碰撞，运行中发现碰撞或限位越界即中止。

首次试验 16 帧，初始最大角误差 0.0597 rad，结束时最大角误差 0.0399 rad，连续 5 帧满足 0.05 rad 位置和 0.2 rad/s 速度阈值。阈值较宽，初始姿态本来已接近阈值，结果不表明能恢复大的偏移。0.36 rad/s 是记录期间实际最大关节速度，速度约束应用于目标指令，不保证仿真反馈速度满足同样限制。独立种子 1–8 中，6 个到达该判据，2 个因初始姿态与桌面或抽屉穿透而被拒绝；所有结果均基于一个演示帧，不能推广至其他阶段。

四张图是未标定的仿真视角；腕部视角为跟随末端的位置的自由相机，并非安装和朝向标定过的实物相机。场景无物块，抽屉及桌面位置未对齐实物。该阶段尚未通过人工任务阶段认证，不包括策略闭环、阶段识别、自动找参考点、任务成功评估或真实硬件。样本仅 8–17 帧且是合成域，与当前需要 50 步的真实数据输入不匹配，不能直接作为真实专家训练数据。没有向真机发送命令。
