
# Experimental Results

本目录用于记录 π0 / OpenPI 在 OpenArm + MuJoCo 仿真环境中的实验结果。

## 1. 实验记录要求

每次实验尽可能记录：

- 实验编号与日期
- 代码版本
- 模型及权重版本
- 数据集名称与版本
- 关键配置参数
- 测试初始状态与随机种子
- 实验结果与失败原因

## 2. 核心评估指标

### 任务成功率

成功完成任务的测试次数 / 总测试次数。

需要提前明确任务成功的判定条件。

### 任务完成时间

记录从任务开始到满足成功条件所需的时间。

### 推理延迟

记录模型生成动作所需的时间，并说明统计口径。

### 失败模式

记录抓取失败、动作越界、执行异常、任务未完成等实际观察到的问题。

具体分类应根据真实实验情况确定。

## 3. 推荐记录格式

| 实验编号 | 模型版本 | 测试次数 | 成功次数 | 成功率 | 平均完成时间 | 推理延迟 | 备注 |
|---|---|---:|---:|---:|---:|---:|---|
| 待填写 | 待填写 | — | — | — | — | — | 尚未开展正式评估 |

## 4. 文件管理

- 使用 CSV 保存结构化指标。
- 使用 Markdown 记录实验分析和失败原因。
- 演示视频和大型日志优先保存在独立存储中。
- 在文档中记录文件位置及其对应的实验编号。
- 不得编造实验数据或将未经验证的结果标记为正式结果。
