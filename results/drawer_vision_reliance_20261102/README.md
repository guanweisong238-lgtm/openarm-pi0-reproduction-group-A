# 模型到底用不用视觉：020/2000 的通道敏感度探测

探测日期：2026-11-02。只读探测，不训练、不注入状态、不改变判据。

对象：`checkpoints/pi0_openarm_drawer_endpoint_v001/feedback_endpoint_020_randomized_rehearsal/2000`，固定噪声 42、一步端点推理、动作窗口 4，与正式评估同配置。

入口：`scripts/a2_pi0/probe_drawer_vision_reliance.py`；原始记录：[probe_results.json](probe_results.json)。

## 方法

四个探针都**固定机械臂状态**，每次只改一个输入通道，看首步预测动作怎么变。因为模型是确定性的（固定噪声、t=1），同一输入必然同一输出，所以只要输出变了，就一定是那个通道造成的。

| 探针 | 改什么 | 不改什么 |
| --- | --- | --- |
| 1. 抽屉沿把手长度移动 −20/0/+20mm | 场景图像 | 关节状态、关节速度 |
| 2. 抽屉沿拉开方向移动 −20/0/+20mm | 场景图像 | 关节状态、关节速度 |
| 3. 图像消融：全黑 / 换成另一个起点的画面 | 三路 RGB | 关节状态、关节速度 |
| 4. 本体感觉标尺：右臂 joint1 加 0.01 rad | 关节状态 + 图像 | —— |

关节增量用 MuJoCo 雅可比换算成末端位移（毫米），使四个探针可比。

## 结果

### 抽屉位置变化 40mm，模型几乎不动

| 探测 | 步 | 抽屉移动 40mm 引起的首步末端预测变化 |
| --- | ---: | ---: |
| 沿把手长度（Y） | 40 | **1.09 mm** |
| 沿把手长度（Y） | 68 | **1.02 mm** |
| 拉开方向（X） | 40 | **1.34 mm** |
| 拉开方向（X） | 68 | **1.33 mm** |

### 关键对比：视觉 vs 本体感觉

把"每 1mm 物理变化引起的预测末端变化"算成增益：

| 通道 | 物理变化 | 预测末端变化 | **增益** |
| --- | ---: | ---: | ---: |
| 视觉 · 沿把手长度 | 40 mm | 1.02—1.09 mm | **0.026 mm/mm** |
| 视觉 · 拉开方向 | 40 mm | 1.33—1.34 mm | **0.033 mm/mm** |
| 本体感觉 · joint1 | 2.82 mm | 2.56 mm | **0.906 mm/mm** |

**本体感觉的单位敏感度是视觉的 27—34 倍。**

### 视觉消融：它在看，但只看"有没有图"

| 输入 | 动作最大变化 | 首步末端变化 |
| --- | ---: | ---: |
| 三路图像全黑（step 40） | 6.80° | 2.40 mm |
| 三路图像全黑（step 68） | 6.45° | 11.80 mm |
| 换成另一起点画面（step 40） | 0.42° | 0.97 mm |
| 换成另一起点画面（step 68） | 0.79° | 1.99 mm |

全黑图像会明显改变输出，说明视觉通路是通的、没有失效；但换成另一条真实轨迹的画面（两个起点参数相差 3—6mm）几乎不改变输出。

**合起来看：模型从图像里主要提取"场景是否正常"，而不是"把手在哪"。**

## 这解释了此前的失败模式

第一步诊断发现：11/15 条失败是"全程从未把夹持点送到把手 2mm 以内"，且失败集中在 `expanded`（11/30，37%）而 `near` 只有 4/70（5.7%）。

现在有了机理：模型输出的是一条**由本体感觉主导的"平均接近轨迹"**。起点偏差小的时候，平均轨迹恰好能碰到把手（near 95% 成功）；偏差大的时候，平均轨迹碰不到，而模型又不会根据图像去修正（expanded 只剩 63%）。

这也解释了 021/022 为什么补数据仍然退步：**如果新增的视觉-动作配对数据最终仍把模型收敛到以本体感觉为主的平均策略上，加多少标签都不会改变行为。**

## 对下一步的含义

1. **不要先补"对齐阶段"的动作标签。** 本探测表明瓶颈不是标签密度，而是模型对视觉的利用率。在现有机制下再加同类样本，最可能的结果是又一轮 021/022。
2. **要让视觉成为"必要信息"。** 可行方向（均未验证，按代价排序）：
   - **训练时视觉域随机化**：随机遮挡/亮度/相机抖动/背景替换，使"只靠本体感觉"无法拟合标签，迫使模型使用图像；
   - **条件化更强的监督**：在标签生成时让同一关节状态对应多个不同抽屉位置，形成"同样本体感觉、不同目标"的冲突样本，模型只能靠视觉消歧；
   - **改观测几何**：提高全局视角分辨率或增加一个能同时看到夹爪与把手的视角。这会改变实验条件，影响与已有 33/33、84/100、85/100 结果的可比性，必须单独报告，不能悄悄替换。
3. **先做一个最小验证**：用"同本体状态 + 不同抽屉位置"的冲突样本训练一个短课程（几百步），再跑本探测的第 1、2 项。如果增益从 0.03 升到接近 0.3 以上，说明方向对了；如果还是 0.03，说明瓶颈在表征/容量而不是数据组织。

## 边界

- 这是**单帧反事实探测**：固定机器人状态、只动场景或只动关节，不是闭环评估。它回答"输入变多少、输出变多少"，不直接等于闭环成功率。
- 只测了 020/2000 一个权重，只用了 400/401 两个起点、step 40/68 两个时刻。换权重、换起点、换时刻的数值会变，但 27—34 倍的量级差异预期稳定。
- 全黑图像属于分布外输入，它的 6.4—6.8° 变化可能包含"异常检测"效应，不宜当作"视觉贡献"的纯度量。
- 雅可比换算在奇异位形附近会放大误差；step 40/68 不在奇异位形，但这是近似映射。
- 本探测不改变 85/100、84/100、33/33 的任何结论，也不构成模型改进证据。
