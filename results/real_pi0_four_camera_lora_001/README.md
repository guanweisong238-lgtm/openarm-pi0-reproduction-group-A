# 真机四相机 π0：探索性 LoRA 训练

2026-11-21 完成 1,000 步，使用 π0 底座和四路输入：`global`、`chest`、`wrist_left`、`wrist_right`；动作 30 Hz、50 步、双臂 16 维绝对 IK 目标。仅训练 LoRA，batch size 1；初始学习率预热后余弦衰减，详细参数与数据哈希见 `config.json`。训练图像使用 OpenPI 图像增强。输入按用户指示将 22 条轨迹视为通过人工审核，原审核记录不改写。

训练集 18 条、11,942 个完整窗口；验证集 4 条（10、16、17、24），2,495 个完整窗口。训练按固定种子打乱、无放回地处理 1,000 个不同窗口，涉及全部 18 条训练轨迹，但**不足 1 个 epoch**。该划分来自同一次采集，不等同于未见场景泛化测试。

## 结果

- 固定验证探针：每条验证轨迹各取 2 个时间点，共 8 个，使用固定随机键计算无增强的 flow matching 损失；第 0 步平均 0.370427，第 500 步 0.104541，第 1,000 步 0.101783。完整记录见 `validation.jsonl`。
- 扩展抽样：每条验证轨迹均匀取 20 个时间点，共 80 个，两个检查点使用相同抽样和随机键；500 步平均 0.108438、1,000 步平均 0.094887。分别以轨迹为单位的损失见 `expanded_validation.json`。这些仍是训练期间使用过的验证轨迹，非独立最终测试。
- 本进程对最终权重保存和恢复后，单个验证样本损失逐值一致；独立进程重新加载后的 8 个探针平均为 0.101754，相对于训练记录的最大单样本绝对差约 0.000255（此前一次约 0.000636，清理重构后一次约 0.001637），并非严格一致，原因尚未确定；见 `independent_restore_1000.json`。
- 实验运行约 640 秒（训练循环及最终保存校验，不含数据准备和模型加载）；JAX 记录 GPU 峰值约 7.45 GiB。训练及验证未出现非有限值。

这些都是离线 flow 损失，不能作为抓取成功率或真机能力。推理、部署和任务闭环均未验收。

## 资产与限制

- 检查点：`checkpoints/real_pi0_four_camera_lora_001/step_0500/` 和 `step_1000/`。每个目录包含 LoRA 参数、归一化统计和哈希；**只保存适配器**，使用时需要原始 π0 底座、相同的四相机模型及预处理配置。
- 优化器和采样器状态没有保存，当前入口不支持中断续训。`metrics.jsonl` 保存每步结果，`config.json`、数据清单、归一化统计和代码快照保存在本结果目录。
- `scripts/a2_pi0/verify_real_checkpoint.py` 可独立重载最终适配器并重算固定验证；`scripts/a2_pi0/eval_real_four_camera.py` 重算 80 个扩展验证探针。两者需要使用与训练相同的本地数据和底座。
- 完整训练指令：`XLA_PYTHON_CLIENT_PREALLOCATE=false .venv/bin/python -u scripts/a2_pi0/train_real_four_camera.py --steps 1000 --eval-every 100 --save-every 500 --name <新的实验名>`。不会覆盖已有同名实验。
