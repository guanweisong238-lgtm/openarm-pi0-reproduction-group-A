# 验证轨迹 17：完整轨迹离线对照

轨迹 17 不属于训练集，但属于此前用于监控的验证集，与训练轨迹同一次采集。对齐后的第一个机械臂 14 关节观测与任何训练轨迹的首个 16 维状态不完全相同。仅以 14 个手臂关节的欧氏距离比较，它距最近的训练轨迹 14 的初始姿态约 0.18365 rad（最大单关节差约 0.10567 rad）；该计算不证明独立设计的新起点或脱离训练分布，也不涉及物块位置。

使用 1,000 步检查点和 10 步 flow 采样，590 帧、约 19.6 秒，每 15 帧用该验证轨迹**实际记录的真实图像和观测状态**重新预测 50 帧，最后一次使用 50 帧补齐至轨迹结尾，共 37 次预测。按每个起点到下一个起点拼出完整的预测目标序列。该方法使用真实示教观测作为每次预测输入，不是模型自己控制机器人后收到的反馈，称为 teacher-forced 离线评估；不能证明模型从新姿态闭环完成任务。

每帧的预测 IK 目标与真实记录的 IK 目标在双臂 16 维上的平均绝对差约 0.06963 rad；每次重新预测的起点保持真实观测姿态直到下一次重预测的对照约 0.06622 rad。预测目标是安全处理前的 IK 目标，不是电机实际动作；该误差不是任务成功率，且单条轨迹无法说明泛化。输入来自同一批采集。详细来源和数值见 `report.json`、`full_episode.npz`。

查看：`.venv/bin/python scripts/a2_pi0/view_real_full_episode.py`。左上：记录的 IK 目标；中上：模型预测的 IK 目标；另外四格：真实视频。空格暂停或继续，A/D 单帧，J/L 跳约一秒，R 重播，Q 退出。窗口用旧仿真模型逐帧显示目标，夹爪按旧模型范围裁剪；不执行物理、不能复现真实物块／抽屉状态或证明成功。人眼查看不能替代独立初始姿态的闭环试验。
