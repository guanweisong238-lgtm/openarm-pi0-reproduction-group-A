## 控制变量与解释

1. 固定噪声chunk4：2/3通过，seed42姿态2.36°超标。它的下发目标误差随实际观测变化增大，末步目标约4.40mm/2.49°，不应仅归因于执行器。逐步目标误差见chunk4_goals.json。
2. 固定噪声chunk1：1/3通过；seed42约5.52mm/3.80°。更频繁重观测并没有直接改善该有偏输出。
3. 恢复chunk4，只改每次推理的新噪声序列：42/7/99均通过。之后冻结配置，新增未参与选择的0～4也均通过，合计8/8局部片段通过。最大位置约1.99mm、最大姿态约1.06°。
4. 所有噪声序列由试验种子初始化同一个生成器；首块噪声与fixed模式相同，之后逐次抽取，已保存并逐元素校验。可复现不要求每次推理重复同一块噪声。
5. 这是同一训练起点的0.3秒局部证据。没有执行完整接近、接触抓握、拉开或关闭。8/8不是完整任务成功率，也不是不同初始场景的泛化率。

从完全相同初态重放14次实验保存的applied动作，逐步qpos最大差0；8份新噪声序列全部匹配生成器。没有更改动力学、限幅或注入真值。14次中包括失败对照，全部保留。
