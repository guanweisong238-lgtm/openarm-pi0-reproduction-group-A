## 教学结论与限制

1. IO层确实发生更新（保存后参数差值证明），但单独解冻改善很小，不能认定冻结IO是唯一根因。
2. 屏蔽无关左状态改善较大，与此前固定输入敏感性证据一致；它仍未独立解决全部问题。
3. 删除左动作损失没有在此处继续改善。loss占比大不等于删除后必然受益。
4. 残差表示减轻绝对角度重建负担，600步的配对结果较好；尚未证明完整抓握能力或全13条泛化。
5. 50步去噪没有改善，不再把增加推理步数当作当前解决方案。
