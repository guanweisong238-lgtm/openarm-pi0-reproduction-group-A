# 起步超标帧、关节与去噪诊断

本轮只读加载008/300，没有新训练、物理闭环或数据修改。原始主诊断位于`../start9_denoising_diagnosis_20261024/`，本目录补查真实插值轨迹上的速度误差。两个独立进程物理误差有约百分之几毫米数值差别；两次记录器与同进程原始推理的最大输出差均为0。

## 1. 误差范围

27个检查中仅ID12第7、8帧seed42位置超过2mm。主诊断分别2.241、3.017mm，其他25个均<2mm。seed7最坏约1.585mm，seed99约0.999mm。姿态均<2°。不是全部起步观测都失败，也不能通过挑种子消除超标。

## 2. 逐关节与FK替换

主诊断第8帧seed42，右1/2/7关节误差分别约+0.00670/-0.01877/-0.01299rad。第2关节角度误差最大，但末端位置影响取决于运动学及关节间抵消。

这些是离线FK消融，未将真实标签注入模型控制。贡献不是可相加的量，单独修正第2关节反而放大位置误差，说明存在误差抵消；不能按角度MAE直接指定关节权重。

第7、8帧的真实动作已包含增长的右臂位移；seed42预测误差主要沿真实运动方向放大（全9帧右7误差与真实残差余弦约0.92）。其他种子没有相同统一比例，不能据此认定解码重复加当前状态。缓存状态反归一化与原状态最大差1.23e-7rad，qpos映射与原state差0；未来标签已逐项校验。

## 3. 去噪后段

主诊断第8帧seed42：干净动作估计在t=1约1.892mm，在t=.5约2.104mm，在t=.1约3.017mm。第7帧也在后段逐渐超标。这里的干净估计为x_t-t*v，不能把带噪x_t当作机器人实际控制目标。

本目录将输入放到由标签构造的正确插值x_t=t*noise+(1-t)*label，额外检查速度v与noise-label之差：

|0|0.9|0.0492|0.4789|
|0|0.5|0.0832|0.0858|
|0|0.3|0.1431|0.2233|
|0|0.1|0.2655|0.3019|
|0|0.01|0.6155|0.1205|
|8|0.9|0.1484|1.9692|
|8|0.5|0.1872|1.6192|
|8|0.3|0.2704|1.4150|
|8|0.1|0.5161|1.0936|
|8|0.01|1.1556|0.1177|

即使在正确插值轨迹上，靠近目标的速度误差也增大，因此不能将后段问题完全归因于累计偏离。小t的干净估计误差会被乘数t缩小，不能因为最后一列在t=.01变小，就说速度变准了。速度RMSE是标准化量，也不等价于物理FK误差。

现行训练t=0.999*Beta(1.5,1)+.001，理论P(t<.3)约16.4%、P(t<.1)约3.1%。这给出低噪声时间区域覆盖不足的可检验假设，但尚未证明因果；探针仅覆盖帧0/8、seed42，不能泛化到所有任务阶段。

## 4. 下一项最小对照

从同一008/300权重，两组固定关闭增强、首4步权重4、学习率/步数/帧顺序不变，只比较原始时间采样与增加低噪声时间段采样。保留原采样的一部分，避免丢失高噪声覆盖。用完整9×3固定检查和独立重载验收，不只看帧8/seed42，不以修改推理种子或截断去噪来宣布通过。此项尚未训练。

仍沿用最坏位置<2mm、最坏姿态<2°诊断门槛，通过后再进入首9物理控制步，之后才扩大阶段覆盖。
