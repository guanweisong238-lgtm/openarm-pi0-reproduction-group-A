# 1000 步变化量模型：episode 17 离线检查

模型读取四路录制图像和录制关节观测，以 7 步零变化量保持作为首次前缀，随后采用前段预测的七步前缀，每 20 帧重规划，50 步输出，10 次 flow 采样。该零前缀启动策略未专门训练；结果是录制观测驱动的开环目标拼接，不是机械臂物理闭环。比较采用模拟 300 ms 延迟及 583 帧公共范围；episode 17 虽未参加训练，但已用于先前调参与观察，不能称为最终独立测试。

预测与记录的绝对 IK 目标比较：14 个手臂关节的平均绝对误差 0.2903 rad，两个夹爪平均 1.3880 rad。每 100 帧的手臂平均误差依次约 0.119、0.304、0.291、0.272、0.365、0.412 rad。27 个切换处手臂单步变化最大值的中位数为 0.02387 rad。夹爪预测大范围偏离；依据本仿真夹爪范围，有 567 帧越界超过 0.05 rad。仿真范围不等同于已确认的真实硬件机械限位。无法从本实验判断任务能否完成，不能用于真机控制。

`delta_1000_vs_demo.mp4` 是空场景中的目标姿态回放，不是动力学测试；视频中夹爪为了显示被裁剪到仿真范围，真实预测未裁剪。只展示 583 帧，末尾 7 帧不在共同覆盖范围内。`deviation_analysis.json` 保存数值诊断。
