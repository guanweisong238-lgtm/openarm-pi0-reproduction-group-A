## 训练采样核查

`sampling_audit.json`来自实际2000条metrics.jsonl，非采样模拟。
10条轨迹前15帧作为观测共抽到37次，占1.85%；其中5条ready轨迹27次，5条human轨迹10次。
ID12首帧未被直接抽到，前15帧抽到6次、前75帧35次；ID8首帧1次、前15帧4次。
不能把某一首帧未抽中等同于模型没见过邻近场景；动作窗口还会覆盖随后标签。
训练日志中5条ready轨迹首帧seed42位置误差均约58.58～60.51mm，说明是共有薄弱阶段。

## 结论与下一项实验

当前证据支持训练数据上的起步预测不足与闭环早期偏离，不能只归因于验证泛化；
本次单种子、两起点尚不能断言全部训练轨迹或全部种子必然失败。
原示教动作前4步能精确重现，首帧输入与原始数据一致，降低了初始化/短步控制执行错误的可能。
独立示教重放只用于环境校验，未混入模型闭环。

下一项建议是小规模受控续训：先加密train/validation接近段检查帧，再只改变早期阶段采样比例，
固定其他变量，并以起始/接近段动作误差及短闭环作为通过条件。采样不足是待验证假设，
还需排查动作序列质量/多解与输入利用情况；不要直接将37次解释为唯一根因。
