# 变化量动作试验（离线）

先将 22 条轨迹的动作标签处理成变化量，目录 `data/processed/real_delta_actions_v001`。对于观测帧 i，50 步标签从原始目标 i−1 开始：第一步为该目标减去观测帧 i 的关节状态，其余 49 步为相邻目标之差。分别对左右臂七关节和夹爪电机角度处理；只有训练集计算变化量统计。逐轨迹将变化量累加还原的最大误差 4.48e−7 rad。输入状态仍为绝对关节观测。采用先前绝对角模型适配器初始化，训练 100 个窗口；前 7 步真实变化量作为前缀，仅对后 43 步计算损失。验证损失下降不代表收敛，也不能与绝对角模型损失直接比较。

离线 episode 17 比较的第一个动作块来自原绝对角模型，之后 7 步前缀由上一段模型预测获得。采用录制观测和模拟 300 ms 延迟，10 次 flow 采样，不是物理仿真或闭环实验。583 帧内变化量版本未平滑时关节切换处单步最大变化中位数 0.0468 rad，低于绝对角前缀版本 0.2377 rad；但其 14 个手臂关节对记录目标的平均绝对误差为 0.8481 rad，对照为 0.0967 rad。8 步平滑后分别为 0.8478 和 0.1001 rad。动作更连续不能等同于任务动作正确。由于训练仅 100 窗口、绝对角检查点初始化，以及训练时使用记录前缀、推理时使用预测前缀等差异，不能把结果全部归因于变化量表示。

变化量累加可能漂移；前缀沿用上一预测意味着基准可能逐段偏离录制状态，需分析误差随时间和关节分布并改进训练/反馈设计，再评估。结果仅供离线研究，不能直接用于真机。
