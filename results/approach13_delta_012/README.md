## 漂移诊断与教学解释

ID12实际第一步目标误差约0.791mm/0.407°，与缓存BF16首动作0.840mm/0.398°接近；未见首帧数量级的输入/解码不一致。实际同时间点位置误差在第12步超过5mm，第18步超过20mm，第37步超过100mm。ID8更早，第3步超过5mm。目标偏差随着策略自己的观测变化放大。

这些现象符合闭环分布偏移/恢复覆盖不足的表现，但尚未独立证明唯一根因是数据覆盖，也未排除历史状态/速度信息不足等因素。固定离线检查下降，只说明给定示教观测时的输出改善，不保证策略自己产生的新状态下也能接近目标。随机loss尖峰不等同总体退化，完整动态测试暴露了固定帧检查未覆盖的问题。

不能把“没有到原接触点”简单等同所有其他抓法都无效；本次实际两指接触记录为0，因此第一夹持目标明确未通过。报告的接触点距离是诊断量，不用它代替接触评分。
