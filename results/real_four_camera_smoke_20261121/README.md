# 四路相机、50 步 π0 合成输入测试

日期：2026-11-21。测试脚本：`scripts/a2_pi0/smoke_real_four_camera.py`。实验只测试计算链路，不读取或训练真机示教，不保存检查点。

- 硬件：NVIDIA RTX 5060 Ti 16 GB，JAX CUDA；batch size 1。
- 模型：项目内四路 π0，`gemma_2b_lora` / `gemma_300m_lora`，预测 50 步，内部 32 维；加载 `weights/openpi/openpi-assets/checkpoints/pi0_base/params`，冻结参数 bfloat16，LoRA 通过项目原有规则训练。
- 输入：四张 224×224 合成常量图像、合成 state、50 步合成动作和占位 token；没有使用真实任务文本分词、数据对齐或训练数据统计。所有动作步有效。
- 分步加载基础权重成功，用时约 15.38 秒，JAX 记录峰值显存 6,918,961,664 字节。
- 四路、50 步前向损失计算通过：形状 `(1, 50)`，数值有限，均值约 0.009078；截至前向阶段的 JAX 峰值 7,112,845,312 字节。
- 一次 LoRA 反向及参数更新通过：损失约 0.007133、梯度范数约 0.057759、参数更新范数约 0.000163；截至该阶段 JAX 峰值 7,973,474,560 字节（约 7.43 GiB），总耗时约 81.45 秒，包含初始化和编译。

合成输入上的损失仅用于检查数值与梯度，不可解释为任务性能；JAX 分配器峰值不等同显卡总占用，也不保证真实数据流水线和后续配置不会超出显存。尚未验证四路真实图像时间对齐、实际 prompt 分词、轨迹末尾掩码、训练数据归一化和闭环表现。
